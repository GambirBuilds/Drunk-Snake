# Drunk Snake 🐍🍺

A chaotic twist on the classic Snake game.

The longer you survive, the drunker the snake becomes.  
Controls get delayed, movement turns wobbly, and the screen starts glitching. Pure chaos.

## Features

- Classic Snake gameplay (Arrow keys / WASD)
- Increasing input delay over time
- Random control wobble when drunk
- Progressive visual chaos (screen shake, color shifts, cross-eyed snake)
- Drunk meter that fills as you survive
- Score bonus for playing while heavily drunk

## How to Play

1. Open `drunk-snake.html` in any modern browser
2. Click **Start Drinking**
3. Survive as long as you can while the controls slowly betray you

## Controls

- **Arrow Keys** or **WASD** — Move
- No other keys needed

## Tech

- Pure HTML, CSS & JavaScript
- No libraries or frameworks
- Single file — just open and play
